    🔒 金鑰只存在這支手機（這個瀏覽器）裡，不會上傳到任何地方，也不會出現在網站程式裡。

    怎麼拿到免費金鑰？
    1. 用瀏覽器打開 aistudio.google.com，用 Google 帳號登入。
    2. 點左邊或右上角的「Get API key」（取得 API 金鑰）。
    3. 按「Create API key」（建立金鑰），複製那串金鑰（AQ. 或 AIza 開頭）。
    4. 回到這裡貼上，按「存起來」。

    免費金鑰每天有用量上限；語音額度用完時，這裡會自動換下一個語音模型。
